# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's "Report a vulnerability" button
on the Security tab of this repository (private vulnerability reporting).
Do not report them in public issues.

## Supported versions

Only the latest release is supported.

## Response time

Expect a response within 7 days.

## Scope

In scope:

- Sandbox escapes
- Permission bypasses (network, files, sources)
- Secret leaks
